# 경량 PoC UX/UI 명세

> **사이드 프로젝트 화면 명세:** 아래 iOS 화면과 `Mac 3DGS` 문구는 macOS·iOS PoC 기준으로 유지한다. [사이드 프로젝트 안내](../../README.md)를 따른다.

기능 기준: [func-specs.md](../01-func/func-specs.md) · 기술 기준: [tech-specs.md](../03-tech/tech-specs.md)  
참고 구현: [CaptureGuideApp.swift](../../ios/CaptureGuide/CaptureGuideApp.swift), [AppModel.swift](../../ios/CaptureGuide/AppModel.swift), [guides.py](../../poc/server/guides.py)

## 1. 화면 구조

iOS 앱은 상단 네비게이션 바(`촬영 안내 PoC`)와 공통 상태 배너(`model.message`), 하단 4개 탭(`TabView`)으로 구성한다.

| 탭 인덱스 | 탭 이름 (아이콘) | 뷰 / 기능 ID | 역할 |
| --- | --- | --- | --- |
| 0 | 서버 연결 (`network`) | `ConnectionView` (F01) | Mac 주소·개발 토큰 입력, 연결 확인, 로컬 네트워크 설정 안내, 새 프로젝트 시작 |
| 1 | 촬영·업로드 (`video`) | `CaptureView` (F02, F03, F06) | A/B 역할별 촬영, 미리보기 재생, 재촬영, 파일 업로드, 분석 시작 |
| 2 | 작업 진행 (`clock`) | `StatusView` (F04, F07) | `최초 A` / `최초+보완 A+B` 선택, 단계·경과 시간·3DGS 상태 조회, 실패 시 재시도 |
| 3 | 보완 안내 (`viewfinder`) | `GuideView` (F05, F07) | 정합 프레임 수, 상위 3개 추가 촬영 후보(대표 이미지·영역 상자·문구), 한계 문구, 보완 촬영 B 진입 |

## 2. 화면 흐름과 상태 전이

```text
[0. 서버 연결]
   ├─ 연결 성공 & 기존 run 없음 ──────────────▶ [1. 촬영·업로드 (initial A)]
   └─ 연결 성공 & 기존 run 있음 ──────────────▶ [2. 작업 진행]
                                                    ▲
[1. 촬영·업로드]                                    │
   └─ 촬영 → 미리보기 → 업로드 → 분석 시작 ─────────┘
                                                    │
[2. 작업 진행]                                      │
   └─ 전경 2초 간격 조회 → completed & 리포트 수신 ─▶ [3. 보완 안내]
                                                         │
   ◀── 보완 영상 B 촬영 버튼 (role = supplement) ────────┘
```

- **세션 보존:** `Documents/session.json`에 Mac 주소, `project`, `initialCapture`, `supplementCapture`, `initialRun`, `combinedRun`, `localFile`, `role`을 저장한다. 개발 토큰은 기기에 영구 저장하지 않으며 앱 재실행 시 다시 입력한다.
- **폴링 제어:** 앱이 `active`일 때만 2초 간격으로 작업 상태를 조회하고, 비활성화되거나 `completed`/`failed` 상태에 도달하면 폴링을 중지한다.

## 3. 화면별 UI 구성 요소

### 3.1 서버 연결 (`ConnectionView`)

- **입력:** Mac 서버 주소(`http://Mac이름.local:8080`, 연결 중 비활성화), 개발 토큰(`SecureField`)
- **동작:** `연결 확인` 버튼, `앱 설정 열기` 버튼, `새 프로젝트 시작` 버튼(세션 초기화 후 주소만 유지)
- **안내 문구:** 가로 1080p / 30fps / 후면 기본 카메라 / 1배율 / SDR 촬영 조건, 원본 보관 위치(iPhone·Mac), 로컬 네트워크 권한 확인 경로(`설정 → 개인정보 보호 및 보안 → 로컬 네트워크`)

### 3.2 촬영·업로드 (`CaptureView`)

- **역할 구분 헤더:** `initial`일 때 `최초 영상 A · 30~60초`, `supplement`일 때 `보완 영상 B · 10~30초 (분석용 15초 이상 권장)` 표시
- **촬영/미리보기 영역:** 카메라 활성 시 `CameraPreview`(높이 210pt)와 경과 시간(`촬영 N초`), `녹화 시작` / `촬영 종료` / `촬영 취소` 버튼 표시. 촬영 완료 후 `AVPlayer` 미리보기로 전환
- **액션 버튼:** `카메라 열기`(또는 `재촬영`), `영상 업로드`, `분석 시작`
- **전송률 표시:** 업로드 중 `ProgressView`로 `업로드 N%` 표시

### 3.3 작업 진행 (`StatusView`)

- **결과 선택(`RunPicker`):** `최초 A`, `최초+보완 A+B` 버튼으로 조회 대상 run 전환
- **진행 상태:** 상태(`대기`/`처리 중`/`완료`/`실패`), 단계(`프레임 추출`/`SfM 정합`/`영역 분석`), 경과 시간(`경과 N초`), 처리 중 스피너(`ProgressView()`), 실패 메시지 및 코드(`[error.code]`), Mac `3DGS` 준비 상태(`not_started`/`running`/`ready`/`failed`)
- **재시도:** `상태 다시 확인` 버튼, 실패 시 `새 작업으로 재시도` 버튼(새 run ID 생성)

### 3.4 보완 안내 (`GuideView`)

- **요약 헤더:** `최초 A 결과` / `최초+보완 A+B 결과`, `{registered_frames} / {input_frames} 프레임 정합 · {message}`
- **후보 카드 (최대 3개):**
  - 제목: `{rank}. 추가 촬영 후보 · 영역 {region}`
  - 지표: `평균 관측 · 근거 점 N개 · 규칙 기반 참고 점수`
  - 대표 이미지(`GuideImage`): 서버가 생성한 영역 표시 PNG 비동기 로드(실패 시 `이미지 재시도`)
  - 촬영 문구: `표시 영역이 보이는 위치에서 화면에 유지하며 천천히 옆 시점으로 촬영하세요. 이동 가능 여부는 직접 확인하세요.`
- **하단 정보 및 액션:** `report.limitations` 한계 목록, 운영자 관찰 기록(`comparison`이 있을 때), `보완 영상 B 촬영` 버튼, `Mac 3DGS 준비 상태 갱신` 버튼

## 4. 보완 안내 시각화 및 표현 규칙

### 4.1 대표 이미지 생성 (`poc/server/guides.py`)

- 5개 이상의 3D 점이 포함된 영역 중 규칙 점수 상위 최대 3개를 후보로 선정한다.
- 각 후보 영역의 3D 점을 가장 많이 관측한 등록 프레임을 대표 이미지로 선택한다.
- 해당 이미지의 실제 `POINTS2D` 관측 좌표를 감싸는 경계 상자에 여백(`max(10, width*0.1, height*0.1)`)을 더해 이미지 범위 내로 제한한 뒤, 주황색 사각형(`BGR (0, 150, 255)`, 두께 3px)을 그려 PNG로 저장한다.

### 4.2 UX 문구 및 표시 제한

- **허용 용어:** `추가 촬영 후보`, `규칙 기반 참고 점수`, 정합 프레임 수(처리 상태)
- **금지 표현:** `예상 PSNR`, `복원 정확도`, `품질 개선 확률` 등 화질 예측·개선 보장으로 오해될 표현을 사용하지 않는다.
- **방향 화살표 미생성:** 후보 위치·자세가 없으므로 축 방향 화살표, 이동 거리, 안전 경로를 표시하지 않는다.
- **근거 없는 진행률 금지:** 업로드 전송률(`업로드 N%`) 외에 SfM·학습 단계에는 퍼센트 진행률을 표시하지 않는다.
- **근거 부족 처리:** 5개 미만 점의 영역은 후보에서 제외하고, 추천 가능한 영역이 없으면 `안내 근거 부족` 메시지를 표시한다.

## 5. 권한·오류 대응 UX

| 상황 | 화면 동작 |
| --- | --- |
| 카메라 권한 거부 | 거부 안내 문구와 `설정 열기` 버튼 표시 |
| 로컬 네트워크 권한 거부 | `NWConnection` 진단으로 구분 시 로컬 네트워크 허용 경로 안내, 로컬 영상 유지 |
| 서버 미접속 / 연결 오류 | 주소·동일 Wi-Fi·권한 점검 안내, 로컬 영상 유지 |
| 분석 실패 / 앱 재실행 | 실패 코드·메시지 보존, 저장된 프로젝트·run ID로 상태 복구 및 새 작업 재시도 가능 |
