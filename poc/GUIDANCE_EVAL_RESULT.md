# 동일 추가 프레임 수의 안내 효과 검증 — 2026-11-11

**판정: 현재 안내가 일반 촬영보다 효과적이라는 근거를 확보하지 못했다. 원래 방향 안내는 이 후보 집합에서 실행할 수 없었고, 가용 시점 중 추천 방향에 가장 가까운 시점을 고르는 대안도 반복에 따라 균등 선택과 승패가 바뀌었다.**

이는 효과가 없음을 증명한 결과나 두 방식이 동등하다는 결론은 아니다. 공개 실내 장면 하나의 오프라인 탐색 실험이며 실제 사람이 같은 시간 동안 안내에 따라 재촬영한 시험은 아니다.

## 원래 안내와 대안의 구분

최초 A의 기존 분석 결과에서 상위 후보 3개를 그대로 사용했다. 각 영역의 중심과 추천 벡터를 공통 SfM 좌표계로 정렬하고, 추가 후보 30개 카메라의 관측 방향과 내적을 계산했다.

추천 방향과 같은 반구에 있는 느슨한 기준인 `cosine > 0`을 적용해도 가능한 후보는 **0 / 30장**이었다. 세 영역 전체의 cosine 범위는 약 **−0.938~−0.743**으로, 모두 추천 방향의 반대쪽이다. 이는 이 공개 촬영 후보 안에서의 결과이며 실제 공간의 모든 이동 가능 위치를 조사한 것은 아니다.

따라서 아래 학습 비교의 안내 측은 **원래 방향대로 촬영한 결과가 아니다.** 가용 후보 중 추천 방향에 가장 가까운 시점을 고르는 보조 대안(`nearest_direction_proxy`)이다. 이 구분과 실험 조건은 첫 비교 학습 전에 [protocol.json](data/guidance-eval/protocol.json)에 고정했다. 기존 제품의 추천 로직은 수정하지 않았다.

대안의 점수는 상위 3개 영역별 방향 cosine을 기존 `heuristic_risk`에 비례해 가중 평균한 값이다. 높은 순서대로 10장을 선택하며, 평가 렌더링이나 평가 오차를 선택에 사용하지 않았다. 선택된 후보도 여전히 추천 방향의 반대쪽에 있다.

## 비교 조건

| 항목 | 고정 조건 |
| --- | --- |
| 데이터 | 앞선 핵심 PoC의 Mip-NeRF 360 실내 `room` 실사 이미지 100장 |
| 최초 입력 A | 동일한 60장 |
| 추가 촬영 후보 | B 40장 중 평가 10장을 뺀 30장 |
| 추가 입력량 | 모든 방식 10장, 총 학습 입력 70장 |
| 공통 평가 | B의 매 4번째 이미지 10장. 모든 방식에서 동일한 사진·픽셀·카메라·내부 파라미터 |
| 카메라 | 앞선 A+B 100장 SfM의 좌표와 왜곡 보정 결과를 모든 방식에 고정 |
| 초기 점군 | A만으로 생성된 7,577개 점을 공통 좌표계로 변환해 동일하게 사용. B·평가 시점에서 생긴 점은 초기화에 사용하지 않음 |
| 학습 | Brush 0.3.0, 3,000스텝, 최대 해상도 960, 최대 300,000 splat |
| 학습 시드 | 대안·균등 선택은 각각 42와 7. 무작위 선택은 학습 시드 42 |
| 일반 촬영 기준선 | 후보 시간 순서에 균등한 10장, 및 비복원 무작위 10장 선택 3개 |
| 지표 | 공통 10장의 RGB PSNR 평균, RGB SSIM 평균 |

카메라 좌표·내부 파라미터는 평가 이미지를 포함한 전체 100장으로 구한 값을 공유한다. **미래 후보의 카메라 위치를 알고 있는 조건에서 이미지 선택만 비교하는 실험**이다. 평가 이미지는 3DGS 학습 손실에서 제외했지만 SfM에는 사용했다. 별도 공간·별도 촬영 구간의 독립 평가 또는 온라인 안내 시스템 검증으로 해석할 수 없다.

균등 선택은 후보 목록의 양 끝을 포함한 등간격 10장이다. 무작위 선택 3개는 선택 시드 0·1·2로 고정했다. 각 방식의 실제 사진 목록, 공통 평가 이미지의 SHA256, 초기 점군 SHA256과 설정은 protocol에 보존했다. 평가 10장의 카메라 메타데이터가 모든 방식에서 완전히 동일한지 별도로 검사했다.

## 측정 결과

값이 클수록 원본 평가 영상에 가깝다. PSNR은 저장된 8bit 렌더 PNG와 동일 크기 원본의 전체 픽셀 MSE로 계산했다. SSIM은 Gaussian 11×11, sigma 1.5, 경계 5픽셀 제외, 색 채널 평균이다. LPIPS는 측정하지 않았다.

| 방식 | 학습 시드 | 평균 PSNR (dB) | 평균 SSIM | 명령 시간 (초) |
| --- | ---: | ---: | ---: | ---: |
| 안내 근접 대안 | 42 | 23.95432 | 0.80632 | 78.5 |
| 균등 선택 | 42 | 24.23459 | 0.80688 | 76.6 |
| 무작위 선택 0 | 42 | 23.90079 | 0.80213 | 76.3 |
| 무작위 선택 1 | 42 | 23.97013 | 0.80712 | 76.0 |
| 무작위 선택 2 | 42 | 23.95629 | 0.80170 | 75.8 |
| 안내 근접 대안 | 7 | 24.48205 | 0.81620 | 76.1 |
| 균등 선택 | 7 | 23.84250 | 0.80689 | 76.0 |

| 같은 학습 시드의 대안 − 균등 선택 | PSNR 차이 | SSIM 차이 | 대안의 PSNR이 높은 평가 시점 |
| --- | ---: | ---: | ---: |
| 시드 42 | −0.28026dB | −0.00056 | 3 / 10 |
| 시드 7 | +0.63955dB | +0.00931 | 5 / 10 |

두 반복 평균으로는 대안 24.21819dB, 균등 선택 24.03854dB로 대안이 **+0.17964dB** 높다. 그러나 같은 선택 방식 안에서도 시드에 따른 PSNR 차이가 대안 0.528dB, 균등 선택 0.392dB이며, 짝 비교의 승패가 바뀌었다. 이 평균 하나로 일관된 개선이나 통계적 유의성을 주장하지 않는다. 학습 시드 두 개는 독립 공간 두 개가 아니며, GPU·로더 등의 완전한 결정성도 보장하지 않는다.

시드 42의 대안은 무작위 선택 3개의 PSNR 범위인 23.90079~23.97013dB 안에 있었다. 특정 평가 시점에서는 대안이 더 좋고 다른 시점에서는 균등 선택이 더 좋아, 모든 영역을 개선한 결과도 아니다. 두 방식의 같은 카메라 렌더를 열어 비교했으며 수치가 다른 사진·크기·카메라의 비교에서 나온 것은 아닌지 확인했다.

7개 실행 모두 종료 코드 0, 동일 평가 렌더 10장씩 생성, 초기 점군·전체 입력 이미지 해시 일치를 확인했다. 학습 명령 시간 합계는 약 535초이며, 기록된 시스템 memory pressure는 모두 정상(1), swap 사용은 0이었다.

## 결론과 다음 판단

1. **원래 방향 안내의 효과는 입증하지 못했다.** 이 후보 집합에서 추천 방향에 맞는 시점이 하나도 없었다. 현재 규칙은 가시성·장애물·이동 가능 영역을 고려하지 않는다.
2. **보조 대안도 일반 선택보다 일관되게 좋지 않았다.** 두 반복 평균은 작게 높았지만 학습 시드에 따라 승패가 바뀌었다. 우위·동등성·무효과의 통계적 결론을 내릴 실험 규모가 아니다.
3. **프로젝트 전체 중단을 뜻하지는 않는다.** 실제 복원 파이프라인의 실행 가능성과 촬영 안내의 효과는 별도 문제다. 안내 효과를 핵심 차별점으로 주장하려면, 보이는 영역과 이동 가능한 후보를 먼저 제한하고 방향·관측 다양성을 평가하는 규칙으로 다시 검증해야 한다.

후속 검증에서는 별도 방과 최초 촬영 조건을 늘리고, 독립 촬영 구간을 평가용으로 고정하며, 추가 프레임 수뿐 아니라 촬영 시간·이동 거리도 맞춰야 한다. 이번 3,000스텝은 운영 PoC 예산이며 충분히 학습한 최종 품질 순위까지 보장하지 않는다. 이번 결과만 보고 대안이 항상 나쁘거나 항상 좋다고 결론 내리지 않는다.
