# 복원 상태·보완 촬영 지원 검증 — 2026-11-13

후속 요청에 따른 [60+10 사용자 비교 실행표](user-study-session.md)를 별도로 준비했다. 이번 실행은 아래 최대 40장 계획과 구분하며, 동일 A 60장·조건별 추가 10장으로 비교한다. 현재 상태는 촬영 전이며 실제 사용자 효과는 미측정이다.

목표는 사용자가 복원 상태와 관측 근거를 이해하고 보완 촬영을 수행할 수 있는지 확인하는 것이다. v2 시점 선택의 최적성이나 화질 개선을 전제하지 않는다. 현재 실제 촬영 영상은 없으며, 아래는 촬영 전에 고정할 파일럿 절차다.

## 좁힌 연구 질문 — 2026-11-13

> 실내 3DGS 복원에서, 부족한 영역을 대표 사진에 표시하면 초보자가 같은 시간 동안 자유롭게 보완 촬영할 때보다 해당 영역의 재현 품질을 더 개선할 수 있는가?

검증 대상은 **부족한 영역의 표시가 실제 보완 촬영에 도움이 되는가**다. 여기서 부족한 영역은 관측 근거로 제시하는 후보이며, 실제 화질 저하를 정확히 예측한다고 전제하지 않는다. 최적 촬영 방향, 새로운 품질 예측 모델, 공간 전체 완성도는 이번 연구 질문의 범위에서 제외한다.

| 항목 | 고정할 내용 |
| --- | --- |
| 대상 | 3D 복원 촬영 경험이 없는 초보자. 참여 전 경험 여부를 기록 |
| 안내 조건 | 부족한 영역이 표시된 대표 사진을 보고 보완 촬영 |
| 자유 조건 | 영역 표시 없이 같은 대표 사진을 보고 자유롭게 보완 촬영 |
| 공통 조건 | 동일한 최초 영상 A, 상태 정보·대표 사진·설명 시간, 보완 촬영 20초, 동일 선택 프레임 수·복원 설정 |
| 주 평가 | 보완 전에 고정한 평가 영역(ROI)의 A 대비 재현 품질 변화가 안내/자유 조건에서 어떻게 다른지 비교 |
| 보조 평가 | 사전 지정 대상 찾기 성공 여부·찾는 데 걸린 시간. 자유 조건 촬영자에게 대상 정답은 사전에 알려주지 않음 |
| 파일럿 범위 | 서로 다른 작은 정적 실내 장면 3개 |

첫 파일럿의 주 평가는 아래 절차에 따라 고정 시점·ROI에서 누락·끊김·번짐을 개선/동일/악화/판정 불가로 기록한다. 평가 원본과 렌더의 자세·노출·픽셀 정렬이 검증되기 전에는 ROI PSNR/SSIM을 주 지표로 사용하지 않는다. 대상 찾기는 촬영 영상과 행동 기록을 사전 지정 ROI에 대응시켜 판정하고, 확인할 수 없으면 판정 불가로 남긴다.

[저장 실사 PoC](reports/supplement-effect-result.md)의 두 시드 평균 PSNR +4.482dB는 추가 이미지의 효과를 확인한 결과다. 영역 표시의 효과를 입증한 결과는 아니며, 위 연구 질문은 실제 촬영 비교 전까지 미검증으로 둔다. 장면 3개 파일럿에서 차이가 없거나 악화돼도 그대로 보고한다.

작업용 프로젝트 제목: **관측 근거 시각화를 활용한 실내 3DGS 보완 촬영 지원 시스템**.

## 지금 확인한 것

[저장 결과 점검](reports/capture-support-result.md)은 보고서와 SfM의 수치 일치, 후보 이미지 참조와 상자 범위, 동일 초기 프레임의 보완 후 등록 여부를 검증한다. 정합률은 공간 완성도가 아니다. 완전 미관측 영역은 현재 알고리즘이 검출하지 못한다. 전후 region ID나 point ID도 직접 비교하지 않는다.

## 실제 촬영 파일럿

1. 서로 다른 작은 정적 실내 장면 3개를 준비한다. 각 장면에서 초기 A를 30초 촬영하고 분석한다. 물체·조명·카메라 설정을 유지한다. A가 처리 실패하면 상태 표시 실패로 기록하고 효과 비교에서는 제외하되 실패 건수는 보고한다.
2. 보완 전에 운영자가 A 렌더에서 부족한 실제 물체/영역을 최대 3개 지정한다. 대표 사진의 수동 ROI, 물체 이름, 고정 평가 시점 3개와 A 화면을 저장한다. 후보가 그 영역을 표시하는지도 기록한다. ROI는 결과를 본 뒤 바꾸지 않는다. 완전 미관측 영역은 수동 지정임을 명시한다.
3. 가능하면 장면별 서로 다른 초보 촬영자 2명을 안내/자유 조건에 무작위 배정한다. 두 조건에 같은 A 상태 정보·대표 사진·설명을 제공하고, 안내 조건에만 부족한 영역을 표시한다. 자유 조건은 표시 없는 같은 대표 사진을 보고 부족한 부분을 스스로 보완한다. 양쪽에 같은 촬영 시간 20초와 같은 설명 시간을 준다. 운영자의 평가 ROI나 대상 정답을 자유 조건에 알려주지 않는다. 한 사람이 두 조건을 수행하면 안내를 본 뒤 생기는 학습 오염이 있으므로 탐색 사례로만 기록한다.
4. B-guide와 B-free를 각각 촬영한다. 동일한 A를 별도 실험 프로젝트에 복제해 A+B-guide, A+B-free를 따로 분석한다. 두 B를 합치거나 한 조건의 결과를 다른 조건에 제공하지 않는다. 파일 해시로 A 동일성을 확인한다.
5. 각 B는 동일 설정으로 최대 40프레임을 추출한다. 실제 선택 수가 다르면 처리 실패/선명도 제외 이유를 기록하고 동일 예산 비교 성립 여부를 표시한다. 더 잘 나온 프레임을 사후 선택하지 않는다.
6. A 및 두 보완 결과를 동일 Brush 설정(3,000스텝, 긴 변 960, 최대 30만 splat, 시드 42·7)으로 순차 처리한다. 설정·버전·실제 시간·실패 로그를 보존한다. 공통 A 카메라로 정렬하고 기존 상대 RMSE 기준 0.1을 적용한다. 실패하면 렌더 비교 불가로 남긴다.
7. 고정 평가 시점에서 A/guide/free 대응 화면을 저장한다. 조건 이름을 가린 뒤 사전 지정 ROI의 누락·끊김·번짐을 개선/동일/악화/판정 불가로 기록한다. 두 평가자의 의견이 다르면 불일치를 그대로 남긴다. 육안 판단을 정량 표면 완성도로 표현하지 않는다.

독립 평가 영상은 학습에 넣지 않고 별도로 보관한다. 실제 평가 카메라 자세·노출·픽셀 정렬을 검증하기 전에는 해당 영상과 렌더의 PSNR/SSIM을 계산하지 않는다. 첫 파일럿은 상태 이해·촬영 수행과 고정 시점 육안 비교에 집중한다.

## 판정 기준

| 구분 | 기록·판정 |
| --- | --- |
| 상태 이해 | 촬영자가 등록 수의 의미와 표시 영역을 자기 말로 설명하는지 기록. 정합률을 완성도로 이해하면 문구 개선 필요 |
| 수행 가능성 | 안내 영역을 실제로 찾았는지, 촬영 완료 여부, 안내 이해 시간, 막힌 이유. 후보 없음도 별도 결과 |
| 처리 연결 | A 보존, 두 B 분리, 업로드·분석 성공/실패, 초기 미정합 프레임 회복/기존 등록 프레임 손실 |
| 영역 변화 | 사전에 고정한 ROI별 개선/동일/악화/판정 불가와 근거 화면. 안내 조건과 자유 조건을 나란히 보고 |
| 제품 진행 | 상태 오해·영역 식별 실패가 있으면 문구/표시를 먼저 수정. P0/P1 통과는 기존 실기기 기준을 충족해야 함 |
| 효과 주장 | 장면 3개는 파일럿이며 통계적 우위·일반화를 주장하지 않음. 우위가 없더라도 실패를 숨기지 않고 지원 도구로서의 사용성 결과와 분리 |
