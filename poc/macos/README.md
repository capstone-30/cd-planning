# macOS 서버·Brush 환경

Mac에서 공용 FastAPI 서버, FFmpeg·COLMAP, Brush를 실행하는 환경과 운영 문서를 관리한다. iPhone 앱 소스와 화면 명세는 [iOS](../ios/README.md), Android 웹 화면은 [Android](../android/README.md)에 있다.

- [Mac 설치·서버 실행](docs/05-ops/runbook.md)
- [Mac 처리·자원 예산·서버 기술 명세](docs/03-tech/tech-specs.md)
- [공용 Python 코드·테스트·실험 기록](../shared-poc/README.md)

Python 코드·데이터는 `../shared-poc/poc/`를 사용한다. iOS 개발용 Xcode는 앱 빌드 시 별도로 필요하다. 기존 실측과 실제 촬영 P0/P1 완료 여부는 [공용 검증 기록](../shared-poc/docs/04-test/validation.md)을 따른다.
