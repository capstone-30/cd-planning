# 본 프로젝트 뷰어·사용자 흐름

기준일: 2026-11-14 · 초기 UI: Nerfstudio 기본 웹 뷰어

**입력 준비 → 데이터 처리 결과 확인 → Splatfacto 학습 시작 → 브라우저에서 진행·복원 결과 확인 → 실행 기록과 결과 저장** 순서로 사용한다. 별도 제품 화면을 만들기 전에 기본 제공 도구로 전체 흐름을 확인한다.

- 처리·학습의 성공·실패는 실제 종료 상태와 로그로 판정한다.
- A와 A+B 결과는 실행 ID·입력·설정을 구분해 연다. 좌표와 시점 대응을 확인하기 전에는 동일 시점 비교로 표시하지 않는다.
- 초기 뷰어는 학습·복원 결과 확인용이다. 비교 화면, 촬영 보완 안내 UI, 충돌·1인칭 체험은 후속 설계 대상이다.

뷰어 접속 주소·원격 접속 방식·재로딩 절차는 실제 환경 검증 후 [운영 안내](../05-ops/runbook.md)에 기록한다. 현재 접속 가능한 본 프로젝트 뷰어는 검증하지 않았다.

iOS 탭·카메라·업로드·Mac 상태 문구는 [사이드 프로젝트 UX/UI 명세](../../side-projects/macos-ios-poc/docs/02-uxui/uxui-specs.md)에서 유지한다.
