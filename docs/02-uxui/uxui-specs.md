# 사용자 흐름

입력 준비 → 처리 결과 확인 → 학습 → 기본 웹 뷰어에서 진행·복원 확인 → 기록·결과 저장.

- 성공·실패는 종료 상태와 로그로 판정한다.
- A/A+B는 실행 ID·입력·설정을 구분한다. 좌표·시점 대응 전에는 동일 시점 비교로 표시하지 않는다.
- 비교·촬영 보완 UI·충돌·1인칭 체험은 후속 설계다.

뷰어 접속·재로딩은 검증 후 [운영 문서](../05-ops/runbook.md)에 기록한다. 기존 앱 화면은 [iOS PoC 명세](../../poc/ios/docs/02-uxui/uxui-specs.md)를 따른다.
