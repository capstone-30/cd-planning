# 본 프로젝트 기술 명세

기준일: 2026-11-14 · 상태: 설계·스택 확정, 실행 검증 전

[3DGS 확정 스택](3dgs-stack.md)을 구현 기준으로 사용한다.

```text
사진·영상 입력
  └─ Ubuntu + NVIDIA GPU + CUDA
       ├─ Nerfstudio 데이터 처리 + COLMAP: 프레임·카메라·희소 점군
       ├─ Splatfacto (Python + PyTorch + gsplat): 3DGS 학습
       ├─ Nerfstudio 기본 웹 뷰어: 학습 진행·복원 결과 확인
       └─ 실행 설정·로그·체크포인트·내보낸 결과 저장
```

## 실행·비교 원칙

- 설치 호환 조합과 GPU·VRAM을 실제 환경에서 확인하고 패키지·드라이버·실행 인수를 기록한 뒤 버전을 고정한다.
- A와 A+B 학습은 별도 출력 경로에 동일 설정으로 실행한다. 기존 결과를 덮어쓰지 않는다.
- COLMAP 카메라·점군을 기존 분석기에 연결하는 경우 입력 형식과 좌표 변환을 검증한다. 완전 미관측 영역 검출이나 화질 예측이 된다고 가정하지 않는다.
- 전후 비교는 SfM 좌표계와 평가 시점 대응을 확인한다. 정렬하지 않은 결과를 같은 영역·시점의 정량 비교로 취급하지 않는다.
- 초기 파이프라인은 Nerfstudio 제공 도구로 연결한다. 별도 작업 API·큐·DB·자체 뷰어의 도입 여부는 기본 경로 검증 후 결정한다.

`poc/shared-poc/poc/`의 Mac API와 Brush 실행 연동은 기존 PoC 구현이다. 재사용 여부는 새 스택 검증 후 판단하며 본 프로젝트의 필수 전환 대상으로 두지 않는다. Mac 16GB 예산과 Brush 설정을 Ubuntu GPU 환경에 그대로 적용하지 않는다.
