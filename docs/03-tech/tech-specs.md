# 기술 원칙

구성은 [확정 스택](3dgs-stack.md), 실행 상태는 [검증표](../04-test/validation.md)를 따른다.

- 실제 호환 조합·GPU·VRAM·버전·실행 인수를 확인한 뒤 버전을 고정한다.
- A/A+B는 동일 설정·별도 경로로 실행하고 기존 결과를 보존한다.
- 비교 전 SfM 좌표와 평가 시점을 정렬한다. 기존 분석기 재사용 시 입력 형식·좌표 변환도 검증한다.
- 관측 근거 분석을 완전 미관측 영역 검출·화질 예측으로 해석하지 않는다.
- 초기에는 제공 도구를 연결한다. 별도 API·큐·DB·자체 뷰어 도입은 기본 경로 검증 후 결정한다.

[기존 Mac·Brush 구현](../../poc/macos/docs/03-tech/tech-specs.md)의 재사용·이관 범위는 [공통 목표 스택](3dgs-stack.md)의 이관 절차를 따른다. 기존 Python API 환경과 학습 환경을 분리하고, Mac 16GB 자원 예산을 Ubuntu GPU에 적용하지 않는다.
