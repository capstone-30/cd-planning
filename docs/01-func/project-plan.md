# 프로젝트 계획

기준일: 2026-11-14 · 지도교수: 전광일 · 제출 예정일: 2026-11-27

사진·영상으로 실내 3DGS를 복원하고 브라우저에서 확인한다. [확정 스택](../03-tech/3dgs-stack.md)으로 [기능 요구](func-specs.md)를 구현하며, 완료 여부는 [실행 검증](../04-test/validation.md)으로 판정한다.

개발 순서: 환경·버전 확인 → 데이터 처리 → 학습 → 뷰어 → 재로딩·내보내기.

촬영 보완 연구 질문은 “부족한 영역 표시가 같은 시간의 자유 보완 촬영보다 영역 품질 개선에 도움이 되는가?”다. 효과는 미입증이며, 기본 복원 경로 검증 후 실험 절차를 확정한다. 품질 예측·최적 촬영 방향·자체 비교 뷰어·충돌·1인칭 체험은 후속 범위다.
