# 실내 3DGS 복원 프로젝트 계획

기준일: 2026-11-14 · 지도교수: 전광일 · 제출 예정일: 2026-11-27

사진·영상 입력을 처리하고 3D Gaussian Splatting으로 실내 공간을 복원해 브라우저에서 확인하는 파이프라인을 구축한다. 데이터 처리부터 학습·뷰어까지 빠르게 연결하기 위해 **Nerfstudio + Splatfacto**를 채택한다.

## 현재 개발 범위

1. 사진·영상 입력을 Nerfstudio 데이터 처리 도구와 COLMAP으로 처리한다.
2. Ubuntu + NVIDIA GPU + CUDA에서 Splatfacto를 학습한다. 실행 기반은 Python + PyTorch + gsplat이다.
3. Nerfstudio 기본 웹 뷰어에서 학습 진행과 복원 결과를 확인한다.
4. 입력·버전·설정·로그·체크포인트 및 내보낸 결과를 보존해 재실행할 수 있게 한다.

촬영 보완 연구는 기존 관측 근거와 보완 영역 표시 실험을 참고한다. 연구 질문은 “부족한 영역 표시가 같은 시간의 자유 보완 촬영보다 영역 품질 개선에 도움이 되는가?”이며 아직 입증되지 않았다. 새 스택의 기본 복원 경로를 먼저 검증한 뒤 실험 절차를 별도로 확정한다.

품질 예측 모델, 최적 촬영 방향, 자체 비교 뷰어, 충돌 처리와 웹 1인칭 체험은 후속 연구·기능이다. iOS 촬영 앱과 Mac·Brush 지원은 [기존 PoC](../../poc/macos/README.md)에서 유지한다.

## 개발 순서와 완료 기준

환경 호환 조합 확인·버전 기록 → 실제 입력 데이터 처리 → Splatfacto 학습 → 웹 뷰어 확인 → 체크포인트 재로딩·결과 내보내기 순서로 검증한다. 실제 실행 기록이 있어야 완료로 판정하며 기존 Brush 결과를 새 스택의 성공 근거로 사용하지 않는다.

[기능 명세](func-specs.md), [확정 스택](../03-tech/3dgs-stack.md), [검증 계획](../04-test/validation.md)을 따른다. 현재 새 스택은 문서 채택 단계이며 실행 검증 전이다.
