# 본 프로젝트 기능 명세

기준일: 2026-11-14 · 대상: Ubuntu + NVIDIA GPU + CUDA

사진·영상에서 실내 3DGS를 생성하고 Nerfstudio 기본 웹 뷰어로 확인한다. [확정 스택](../03-tech/3dgs-stack.md)을 따른다.

| 기능 | 요구 사항 |
| --- | --- |
| 입력 준비 | 사진 또는 영상에서 처리 데이터를 준비하고 입력 경로·선택 조건을 기록 |
| 데이터 처리 | Nerfstudio + COLMAP으로 카메라 정보와 희소 점군을 생성하고 실패 로그 보존 |
| 학습 | Splatfacto로 학습하고 설정·버전·진행·종료 상태·체크포인트 기록 |
| 결과 확인 | Nerfstudio 기본 웹 뷰어로 학습 상태 및 복원 결과 확인 |
| 결과 보존 | 체크포인트 재로딩과 결과 내보내기 확인, 산출물 경로 기록 |
| 보완 전후 실험 | A와 A+B를 별도 실행하고 동일 학습 설정 기록. 시점·좌표 정렬을 확인한 뒤 비교 |

완료 기준은 실제 입력의 처리·학습·뷰어 확인·재로딩·내보내기를 실행 기록으로 확인하는 것이다. 실패한 처리를 성공으로 표시하거나 정합 수·Gaussian 수를 화질로 표현하지 않는다.

기본 뷰어로 동일 시점 비교가 가능한지는 검증 대상이다. 자체 비교 UI·충돌·1인칭 체험과 iOS·Mac 지원은 현재 필수 범위에 포함하지 않는다. 기존 앱의 P0/P1 기준은 [사이드 프로젝트 기능 명세](../../side-projects/macos-ios-poc/docs/01-func/func-specs.md)에서 관리한다.
