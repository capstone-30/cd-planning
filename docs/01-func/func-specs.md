# 기능 명세

[확정 스택](../03-tech/3dgs-stack.md) 기준. 완료 판정은 [검증표](../04-test/validation.md)를 따른다.

| 기능 | 요구 사항 |
| --- | --- |
| 입력·처리 | 사진·영상의 경로·선택 조건을 기록하고 카메라·희소 점군 생성 |
| 학습 | 진행·종료 상태와 버전·설정·로그·체크포인트 보존 |
| 결과 확인·보존 | 기본 웹 뷰어 확인, 체크포인트 재로딩·내보내기 및 산출물 경로 기록 |
| 보완 전후 실험 | 최초 A와 보완 포함 A+B를 동일 설정·별도 경로로 실행하고 좌표·시점 대응 확인 |

실패를 성공으로, 정합 수·Gaussian 수를 화질로 표시하지 않는다. 기본 뷰어의 동일 시점 비교 가능 여부는 검증 대상이다. 후속 범위는 [계획](project-plan.md), 기존 iPhone P0/P1은 [PoC 명세](../../poc/ios/docs/01-func/func-specs.md)에서 관리한다.
