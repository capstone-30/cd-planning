[기존 PoC 검증 기록](../../poc/shared-poc/docs/04-test/validation.md)의 Mac·Windows·Brush 실측과 기존 코드 테스트는 해당 PoC의 증거로만 사용한다. 본 프로젝트의 실행 성공 또는 사용자 효과를 뜻하지 않는다.
