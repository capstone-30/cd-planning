# 검증 계획·현황

2026-11-14: **스택 확정, 아래 항목 모두 미검증.** 기존 Brush 실측·코드 테스트는 새 스택의 성공 근거가 아니다.

프로젝트·PoC의 목표 스택은 통일했지만 NVIDIA GPU는 확보 예정이며 실행 코드 이관은 미완료다. 아래 검증과 기존 분석기의 입력·좌표 호환, 학습 명령·상태·실패 처리 테스트를 마쳐야 PoC 이관 완료로 판정한다. [비교·이관 범위](../03-tech/3dgs-stack.md)를 따른다.

| 항목 | 통과 기준 |
| --- | --- |
| 환경 | GPU·VRAM·드라이버 및 CUDA·PyTorch·Nerfstudio·gsplat 호환·실제 버전 기록 |
| 처리 | 실제 사진·영상의 COLMAP 처리 성공, 카메라·희소 점군 확인 |
| 학습 | Splatfacto 정상 종료, 설정·로그·체크포인트 보존 |
| 뷰어 | 브라우저에서 학습 진행·복원 결과 확인 |
| 재사용 | 체크포인트 재로딩·내보내기 성공 |
| A/A+B | 동일 설정·별도 결과 보존, 좌표·시점 대응 및 비교 가능 여부 기록 |

단계별 시간·자원 사용량을 실측한다. 촬영 보완 효과는 별도 실험으로 평가하며 입력·시점·ROI를 결과 확인 전에 고정하고 학습·평가 데이터 사용 범위를 기록한다.
