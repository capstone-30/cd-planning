# 종료한 촬영 시점 선택 실험 — 2026-11-13

공개 Mip-NeRF 360 `room` 장면의 오프라인 실험이다. 실제 사용자의 안내 재촬영 효과나 다른 공간에서의 일반화는 검증하지 않았다.

| 시도 | 확인 결과 | 결정 |
| --- | --- | --- |
| 관측 반대 방향 추천 | 가용 후보 30장 중 추천 방향에 맞는 후보 0장. 가시성·이동 가능성을 반영하지 못함 | 방향 추천 제거 |
| 추천 방향에 가까운 후보 선택 | 동일 추가 10장 비교에서 균등 선택 대비 PSNR 차이가 시드별 −0.280dB / +0.640dB로 뒤바뀜 | 우위 근거 부족으로 종료 |
| 가시성·시차·중복 관측 기반 v2 | 초기 60장＋추가 10장, 공통 평가 10장, Brush 3,000스텝. Windows 10시드에서 균등 선택 대비 평균 PSNR −0.283dB, SSIM 10/10 낮음 | 제품 적용과 추가 튜닝 중단 |

v2는 Mac에서 메모리 압박으로 두 차례 중단됐고, Windows에서 비교를 완료했다. 초기 관측 점의 증가량이 렌더링 품질 개선으로 이어지지 않았으며, 일부 촬영 구간 누락이 관찰됐다. 원인 전체가 입증된 것은 아니다.

현재 PoC는 복원 상태 표시, 관측 근거가 있는 보완 영역 표시, 최초·보완 결과 보존에 집중한다. 규칙 점수는 화질 예측이 아니며, 실제 촬영 지원 여부는 [촬영 비교 절차](../capture-support-validation.md)로 검증한다.

실험 코드·전용 테스트·상세 설계 및 비교 문서는 제거했다. 로컬 원본 산출물(`poc/data/guidance-eval/`, `poc/data/guidance-v2/`, `poc/data/guidance-v2-seeds10/`)은 보존하지만 현재 실행 기능에는 포함하지 않는다.
